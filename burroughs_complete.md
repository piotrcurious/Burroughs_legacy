“Burroughs-complete machine” is not an established technical term in computing. I would understand it as a deliberately constructed analogue of Turing-complete, but shifted from computation to William S. Burroughs’s theory of language, control, and literary machinery.

The key difference is profound.

A Turing-complete machine can, in principle, execute every computable procedure.

A Burroughs-complete machine would be one capable of performing the entire Burroughsian operation on information: not merely generating text, but recording, cutting, rearranging, replaying, contaminating, feeding back, and disrupting the linguistic control system itself.

Burroughs's cut-up method literally treats existing language as machinable material: texts are segmented and rearranged to produce new combinations. His fold-in technique extends this by superimposing portions of different positions in a text and thereby disrupting ordinary linear temporality. 

But the really interesting part is that the “machine” for Burroughs is not merely a literary metaphor. In Nova Express and the surrounding work, language is itself part of a control machine: repetition, recording and playback reproduce established patterns, while cut-up and related interventions are attempts to interfere with that reproduction. One scholarly account describes his strategy explicitly as feeding scrambled recordings of the machine's own control words back into it until it enters destructive feedback. 

So I would define it approximately like this:

> A Burroughs-complete machine is a machine capable not only of processing representations, but of processing the mechanisms by which representations control subsequent processing.



That gives it several layers.

1. It must be a recording machine.
It has to preserve utterances, images, texts, sounds, commands, etc. Without memory there is nothing to cut up or replay.

2. It must be a segmentation machine.
It can decompose a message into arbitrarily manipulable units: words, phrases, phonemes, images, timestamps, semantic blocks, association blocks.

3. It must be a permutation machine.
It can recombine those units rather than merely summarize or transform them according to conventional linguistic rules.

4. It must be a temporal machine.
It can take material from one position in the sequence and insert it somewhere radically different: effectively manufacturing jumps, loops, anticipations and déjà vu. This is central to the fold-in technique. 

5. It must be a playback/feedback machine.
The output can become input again. This is essential because Burroughs's machine is fundamentally recursive: recordings reproduce themselves, and intervention occurs by altering what gets fed back.

6. It must be capable of attacking its own control grammar.
This is the genuinely Burroughsian criterion. A merely generative AI can produce millions of sentences while remaining completely obedient to the grammar, categories and associations it inherited. A Burroughs-complete system has to be able to alter the constraints under which it produces subsequent material.

7. It must permit sabotage.
The system cannot have “correct language” as an inviolable invariant. Its operations must include corruption, interruption, contradiction, noise, unexpected adjacency and deliberate breakdown. Burroughs's own theoretical vocabulary treats such disruption as resistance to the repetitive control mechanism. 

And there is an especially important final criterion:

8. It must be able to turn the machine against the machine.

This is what makes the analogy much more interesting than simply “a computer that can do cut-ups.”

A conventional generative system is approximately:

input → transformation → output

A Burroughs-complete system would look more like:

input → representation → recombination → output → recording → feedback → modification of the representation rules → recombination → disruption of the rules themselves

That last arrow is the crucial one.

The distinction could therefore be expressed almost mathematically:

\[
\text{Turing completeness}
\approx
\text{universality over computable functions}
\]

whereas

\[
\text{Burroughs completeness}
\approx
\text{universality over transformations of the representational/control system itself}.
\]

This also explains why merely having a sufficiently powerful LLM would not automatically make it Burroughs-complete. An LLM can imitate Burroughsian prose extraordinarily well while remaining structurally conservative: it can generate the appearance of disruption without actually possessing an operation that destabilizes the machinery producing its own associations.

A genuinely Burroughs-complete literary machine would therefore need something closer to:

\[
M_{t+1}=F(M_t,\;x_t,\;y_t)
\]

where \(M_t\) is not merely the machine's memory, but its current production/control regime. The machine must be able to modify \(F\) itself.

That produces a wonderfully strange consequence:

The Burroughs-complete machine is not complete because it can generate every text. It is complete because it can generate, mutate, and sabotage the machinery by which texts become possible.

And that is very close to Burroughs's deepest idea: the real enemy is not a particular sentence or ideology but the reproductive mechanism that makes the same sentences, associations and commands appear inevitable. His cut-up therefore functions less like a literary style than like an intervention into an information-processing system. 

In that sense, Turing-complete is a machine that can compute anything; Burroughs-complete would be a machine that can make the computation itself unstable.
